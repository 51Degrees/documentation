Detailed Description

Utility methods used to handle common memory operations such as allocating memory and freeing it, or reading through continuous memory checking for buffer over or under runs.

Reads one of the pointers above in a single atomic access with acquire order, as the memory tracker changes them while other threads call through them.

On x64 this is the same plain load as an ordinary read. Visual Studio reads an aligned pointer sized volatile in one access, with acquire order on x86 and x64.

◆ fiftyoneDegreesMemoryTrackingStartMeasuring()

void fiftyoneDegreesMemoryTrackingStartMeasuring ( )

Starts measuring the memory the calling thread allocates, as the size functions do.

Resets the counts and points the allocation and free functions at the tracking ones. Until fiftyoneDegreesMemoryTrackingStopMeasuring is called, memory that any other thread allocates is neither counted nor recorded, and memory another thread frees is not taken from the count.

◆ fiftyoneDegreesMemoryTrackingStopMeasuring()

void fiftyoneDegreesMemoryTrackingStopMeasuring ( )

Stops the measurement fiftyoneDegreesMemoryTrackingStartMeasuring started.

Points the allocation and free functions at the standard ones and resets the counts, so read them first.

◆ fiftyoneDegreesUnsetMemoryTracking()

size_t fiftyoneDegreesUnsetMemoryTracking ( )

This function works in collaboration with fiftyoneDegreesSetUpMemoryTracking.

Check if all tracking memory has been freed. Unset memory tracking by setting all Malloc/Free function pointer to standard Malloc/Free functions. Then, reset memory tracking.

Returns
0 if all freed, non 0 if there are memory left unfreed. The returned value is the size of allocated memory left unfreed.
