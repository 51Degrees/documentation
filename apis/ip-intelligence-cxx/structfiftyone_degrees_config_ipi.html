◆ defaultValuesInMemory

bool fiftyoneDegreesConfigIpi::defaultValuesInMemory

When true, the default value of each required property is held in memory when the data set is created, with what reading it takes from the strings and the property types, so reading a default value reads nothing from the file and takes no lock.

Nothing is copied from a collection already loaded into memory, so it has no effect where the values, strings and property types are all loaded, as in HighPerformance when no properties are named. It has no effect when allInMemory is true or when loadRequiredPropertiesOnly applies, as both already hold the default values. True in every configuration.

◆ loadRequiredPropertiesOnly

bool fiftyoneDegreesConfigIpi::loadRequiredPropertiesOnly

When true, and the required properties are some but not all of the properties in the data file, only the data they read is loaded into memory.

That is the parts of the strings, values, profiles, profile groups and profile offsets they reach, in whole records, with the rest read from the file when needed with no cache, and the graphs of their components, each following the graph setting, with the graphs of other components read from the file. Other collections follow their own settings. It has no effect when no property or every property is required, or when allInMemory is true. True in the HighPerformance configuration only.
