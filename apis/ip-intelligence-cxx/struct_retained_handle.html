RetainedHandle Struct Reference

Detailed Description

A handle and what keeps its memory allocated.

A thread can read the active handle from the manager just before another thread replaces it, then read the handle after its last reference has gone. So the resource is freed with the last reference, but the memory of the handle stays until the manager is freed as well, which costs one of these for each replacement.
