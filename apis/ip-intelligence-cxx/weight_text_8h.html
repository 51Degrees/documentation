size_t fiftyoneDegreesIpiGetWeightText ( char * text,
uint32_t rawWeighting )

Writes a weight as fiftyoneDegreesResultsIpiGetValueTexts writes it after a value's colon.

The weight is the raw weighting over FIFTYONE_DEGREES_WEIGHTED_ITEM_MAX_WEIGHT, written to six significant figures with no trailing zeros, and with an exponent when it rounds to less than 0.0001, as printf's g and a C++ stream write a double. No null is written after it.

Parameters
textwhere the weight is written, with room for FIFTYONE_DEGREES_IPI_WEIGHT_TEXT_LENGTH characters
rawWeightingthe weight out of FIFTYONE_DEGREES_WEIGHTED_ITEM_MAX_WEIGHT
Returns
the number of characters written
