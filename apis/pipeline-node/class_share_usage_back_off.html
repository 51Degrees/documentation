ShareUsageBackOff Class Reference

Detailed Description

Decides when usage sharing may send.

Sending pauses for the initial delay once the set number of sends fail within the window. A failed send after a pause multiplies the delay, up to the maximum, and a successful send ends the back-off. Only sending pauses, so evidence is still queued while paused. Each method takes the time from the caller, in milliseconds on the clock that now() reads, so a change to the system time cannot lengthen or skip a pause.
