ShareUsageEvidenceKeyFilter Class Reference

Detailed Description

The ShareUsageEvidenceKeyFilter decides which evidence the 51Degrees ShareUsage service is sent.

Headers are shared unless they are blocked, cookies and session values only when their names start with 51D_, and query string and form parameters only when their names start with 51D_ or are on the list to share. Any other evidence is shared.
