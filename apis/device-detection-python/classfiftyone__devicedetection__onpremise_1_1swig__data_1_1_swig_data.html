◆ close()

fiftyone_devicedetection_onpremise.swig_data.SwigData.close ( self)

Release the native results, which keep the engine's data in memory while they are held, even after the engine is closed.

Values already read are unaffected, and reading a property afterwards raises an exception. Closing the FlowData closes its results.
