FiftyOne.IpIntelligence.Example.Tests.Cloud.TestCloudWebExample Class Reference

Detailed Description

Runs the Cloud GettingStarted-Web example in-process (via its Program.Run entry point, which the example exposes specifically for tests) against the real 51Degrees Cloud service, then drives it over HTTP exactly as a browser would and asserts the rendered page contains the expected IP Intelligence results for a known IP address.

Requires the 51DEGREES_RESOURCE_KEY (or legacy SUPER_RESOURCE_KEY) environment variable to be set. It also requires a trusted HTTPS development certificate, because the example binds its configured HTTPS endpoints on start-up (run dotnet dev-certs https –trust once if start-up fails with a certificate error). The example resolves its configuration and views relative to the current directory, so the test runs it from the example's own directory.
