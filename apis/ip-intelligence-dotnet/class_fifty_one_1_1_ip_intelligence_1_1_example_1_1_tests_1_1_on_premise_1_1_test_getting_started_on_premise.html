FiftyOne.IpIntelligence.Example.Tests.OnPremise.TestGettingStartedOnPremise Class Reference

Detailed Description

End-to-end "happy path" tests for on-premise IP Intelligence that go beyond the smoke tests in TestExamples by asserting on the actual detection results for known IP addresses.

To keep these integration tests lightweight, a single LowMemory pipeline is built once for the whole class (ClassInit) and shared across every test, rather than each test loading the (multi-gigabyte) data file into its own engine. The LowMemory profile is used deliberately so the data file is paged from disk instead of loaded wholly into RAM.
