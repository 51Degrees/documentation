FiftyOne.IpIntelligence.Example.Tests.Cloud.TestCloudExamples Class Reference

Detailed Description

Runs the Cloud examples against the real 51Degrees Cloud service (cloud.51degrees.com by default).

Requires the 51DEGREES_RESOURCE_KEY (or legacy SUPER_RESOURCE_KEY) environment variable to be set.

Note that these tests do not generally ensure the correctness of the example, only that the example will run without crashing or throwing any unhandled exceptions.
