◆ IsFreeDataFile()

bool FiftyOne.IpIntelligence.Examples.OnPremise.ExampleUtils.IsFreeDataFile ( IpiOnPremiseEngine engine)
static

Reports whether the engine uses one of the free data files, which have only the registration properties (Lite) or Asn and AsnName (Asn).

The tier cannot tell them apart, as every IP Intelligence file reports the same one. The Enterprise data file adds the range, location and connection properties, IpRangeStart among them.

static

For an example that needs properties only the Enterprise data file has, reports when the data file has none of them, and then says so and where to ask for a copy of the Enterprise data file.

The data file is opened with the low memory profile, which reads little of it.

Parameters
dataFileThe data file the example would use.
purposeWhat the example does, as the start of a sentence, for example "Comparing known locations with IP Intelligence".
propertiesThe properties the example needs.
outputWhere to write the explanation.
contactUsThe link to the contact page, tagged with the example's file so that an enquiry can be traced to the example.
Returns
True when the data file has none of the properties, so the example has nothing to show.
