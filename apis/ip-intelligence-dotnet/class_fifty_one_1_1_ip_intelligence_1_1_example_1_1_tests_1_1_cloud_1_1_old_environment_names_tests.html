FiftyOne.IpIntelligence.Example.Tests.Cloud.OldEnvironmentNamesTests Class Reference

Detailed Description

Tests that the examples still read the resource key, the data file path and the cloud endpoint from the old names of their environment variables when the new name is not set.

The tests change the environment of the whole process, so they run apart from the tests that read it.
