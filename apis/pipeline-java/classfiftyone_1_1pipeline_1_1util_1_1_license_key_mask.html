fiftyone.pipeline.util.LicenseKeyMask Class Reference

Detailed Description

Masks license keys in text written to a log entry or an error message.

A masked key shows only its last 4 characters, with every character before them replaced by '*', so a reader can tell two keys apart but cannot use either. A key of 4 characters or fewer is replaced in full, because its last 4 characters would be the whole key.

The text with every occurrence of each key masked, both as the key is written and as it is encoded in a URL, with upper or lower case hexadecimal digits.

An encoded key is replaced by the encoded form of its masked plain form, so it shows the same last 4 characters. Every occurrence of a key's text is masked, so a key of only a few characters also masks those characters wherever else they appear.
