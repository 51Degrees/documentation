fiftyone.pipeline.engines.fiftyone.data.ShareUsageEvidence Class Reference

Detailed Description

The values usage sharing finds for a request.

The usage sharing element accepts no Evidence, so that cache keys, the ETag and the Vary header never depend on it, and finds what to share here instead. The sharing rules of EvidenceKeyFilterShareUsage then decide which of these are shared.

Every Evidence value, and every value of the web request when the Evidence holds it, keyed without regard to case.

A key in both keeps the Evidence value. The web request itself is not one of the values. Without a web request the values found are the Evidence's own read-only map, as Evidence is already keyed without regard to case and holds no null value, so nothing is copied.
