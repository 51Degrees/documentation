fiftyone.pipeline.web.services.WebRequestEvidence Class Reference

Detailed Description

A read-only view of every value the web integration offered as Evidence for a request, accepted or not, keyed the way Evidence is keyed, such as header.user-agent.

It is added to Evidence as ShareUsageEvidence#HTTP_REQUEST_KEY for the usage sharing element, which accepts no Evidence and reads the request here instead.

It is a map rather than the HttpServletRequest because the usage sharing element does not depend on the servlet API, and the values are copied so that they stay the same once the request is recycled.
