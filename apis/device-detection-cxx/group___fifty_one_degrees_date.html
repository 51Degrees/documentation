Detailed Description

Represents a date in a data set.

Introduction

The Date structure is used to represent dates in data sets. This is a memory efficient way to store a date, and means that the memory from a data file can be read directly into a structure.

bool fiftyoneDegreesDateIsValid ( const fiftyoneDegreesDate * date)

Determines whether the date is a day of the Gregorian calendar, meaning a year above zero, a month from 1 to 12 and a day from 1 to the number of days in that month, with 29 in February of a leap year.

A data file holds whatever bytes it was written with, so a date read from one is checked with this before it is used.

Parameters
datepointer to the date to check, or NULL
Returns
true if the date is valid, otherwise false, including for NULL
