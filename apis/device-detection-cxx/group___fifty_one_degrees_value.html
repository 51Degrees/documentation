Detailed Description

Value of a data set relating to a property.

Introduction

A Value is stored in a values collection and contains the meta data for a specific value of a property in a data set.

Get

A value can be fetched from a values collection in one of two ways:

By Index : the fiftyoneDegreesValueGet method return the value at a specified index. This provides a way to access a value at a known index, or iterate over all values.

By Name : if the index of a value is not known, then the value can be fetched using the fiftyoneDegreesValueGetByName method to find the value in a values collection. This requires that the property the value relates to is also known, as values are only unique within the values which relate to a single property. For example "True" could be a value of many properties.

◆ FIFTYONE_DEGREES_VALUE_IS_MASKED

#define FIFTYONE_DEGREES_VALUE_IS_MASKED ( v)
Value:
((((uint32_t)((v)->urlOffsetOrWeight)) & 0xFFFF0000u) == 0xFF000000u)

Macro to check if a Value's urlOffsetOrWeight field carries a masked weight.

A value is weighted when (urlOffsetOrWeight & 0xFFFF0000) == 0xFF000000. This is distinct from -1 (0xFFFFFFFF, "no URL" sentinel) and from valid non-negative URL offsets.

◆ fiftyoneDegreesValueGetDefaultIndex()

Gets the index in the values collection of the value the metadata gives as the property's default.

The text fiftyoneDegreesValueGetDefaultText gives is searched for among the property's values, each compared as the type propertyTypes gives the property by its name. So a default that is not among the property's values has none, and a property with no default value index has the value with an empty name when it has one.

exceptionpointer to an exception data structure to be used if an exception occurs. See exceptions.h
Returns
the 0 based index of the value in the values collection, or -1 when the property has no such value or a value, a type or a name cannot be read

Gets the text the metadata gives as the property's default value.

This is the name of the value at the property's default value index, written as fiftyoneDegreesValueGetText writes it with a number written to #FIFTYONE_DEGREES_MAX_DOUBLE_DECIMAL_PLACES places. Those are the most places the search in fiftyoneDegreesValueGetDefaultIndex writes a number to, so a default stored with more places than the metadata shows for a value is still found. A property with no default value index has an empty text. A default that is read but cannot be written gives NULL rather than an empty text, so it is not taken for a value with an empty name. The text is written into buffer when it fits, and otherwise into memory the caller frees, as fiftyoneDegreesStoredBinaryValueToText describes.

◆ fiftyoneDegreesValueGetText()

char * fiftyoneDegreesValueGetText ( const fiftyoneDegreesCollection * strings,
const fiftyoneDegreesCollection * propertyTypes,
const fiftyoneDegreesValue * value,
uint8_t decimalPlaces,
char * buffer,
size_t bufferLength,
fiftyoneDegreesException * exception )

Gets the text of the value's name as the metadata gives it.

The name is read as the type the value's property is stored as, which propertyTypes gives by the value's property index, and a number is written to at most decimalPlaces places after the point. A data set that stores every value as a string has no property types and passes NULL. The text is written into buffer when it fits, and otherwise into memory the caller frees, as fiftyoneDegreesStoredBinaryValueToText describes. A name the strings collection gives no value for has an empty text. So does a name that is read but cannot be written, such as an IP address of a length no address has or an area of an unknown geometry, and no exception is then set.

Parameters
stringscollection containing the value names
propertyTypescollection of the type each property's values are stored as, or NULL when every value is stored as a string
valuethe value to get the text of
decimalPlacesthe most places to write after the decimal point
buffermemory the text is written into when it fits
bufferLengththe bytes buffer holds
exceptionpointer to an exception data structure to be used if an exception occurs. See exceptions.h
Returns
the null terminated text, or NULL when the type or the name cannot be read or memory cannot be allocated

◆ fiftyoneDegreesValueGetWeight()

uint16_t fiftyoneDegreesValueGetWeight ( const fiftyoneDegreesValue * value)

Gets the weight from a Value record as a uint16_t (0–65535), or 0 if the value is not weighted.

The weight is stored in the lower 2 bytes of urlOffsetOrWeight when the upper 2 bytes match the 0xFF00 mask. To convert to a proportion: (double)weight / UINT16_MAX
