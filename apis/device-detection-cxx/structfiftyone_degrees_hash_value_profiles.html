Detailed Description

Index from each value of the properties named when the data set is initialised to the profiles holding it, so those profiles are found without reading every profile.

Property i is the first in the properties collection named names[i]. Each of its values has a key, from firstKeys[i] to firstKeys[i + 1] - 1, in the order of the values collection from firstValueIndexes[i]. The profiles holding the value with key k are profiles[starts[k]] to profiles[starts[k + 1] - 1]. Each is a position in the profile offsets collection, in ascending order, which is the order of the profiles in the data file.
