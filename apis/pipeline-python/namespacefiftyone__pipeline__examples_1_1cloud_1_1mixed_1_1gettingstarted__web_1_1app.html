◆ create_pipeline()

create_pipeline ( logger,
resource_key = None,
license_key = None,
cloud_endpoint = None,
cloud_request_origin = None )

Create the pipeline.

A cloud request engine makes one request to the cloud service each time flow data is processed, and the engines after it read the IP intelligence, translated country names and device detection results from the answer. The PipelineBuilder adds the elements that write the client-side JavaScript and set the response headers.

The key in use has to carry device detection or IP intelligence properties. The page shows as unknown whatever the key does not carry, and shows no country list without the translated country names.
