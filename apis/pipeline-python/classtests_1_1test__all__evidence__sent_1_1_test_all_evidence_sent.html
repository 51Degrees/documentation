tests.test_all_evidence_sent.TestAllEvidenceSent Class Reference

Detailed Description

A cloud-only pipeline, so the Cloud Request Engine is the only element and its accepted Evidence is the list the stand-in service gives, which holds query.User-Agent alone.

Everything else is Evidence no element in the pipeline accepts, and the engine still sends it.
