Detailed Description

A data file update service is attached to a pipeline and manages the download of datafiles used by engines.

fiftyone_pipeline_engines.datafile_update_service.DataFileUpdateService.track_local_data_file_changes ( self,
data_file )

Check for local changes to a datafile.

Used by the file system watcher. A refresh that fails is logged, and reported with AUTO_UPDATE_REFRESH_FAILED as on the update route. The next check is scheduled whatever happens, so that a later file is still picked up, until the data file is unregistered. @type data_file: DataFile

Stop the checks and updates of a datafile, for example when its engine is closed.

Checks already scheduled are cancelled, and a check already running schedules no other, so nothing is left holding the data file or its engine. @type data_file: DataFile
