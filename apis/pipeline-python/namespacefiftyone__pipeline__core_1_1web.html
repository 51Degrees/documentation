◆ javascript_response()

javascript_response ( pipeline,
request,
max_age_seconds = CLIENT_SIDE_MAX_AGE_SECONDS )

Process a request for the client-side JavaScript and answer with the JavaScript the pipeline's JavaScriptBuilder writes, with the cache headers the web integration specification sets.

The ETag is a weak entity tag, W/"...", hashed from the evidence the request supplied that the pipeline's elements accept. A GET or HEAD request whose If-None-Match header matches it, by the weak comparison of RFC 9110 section 13.1.2, gets a 304 without being processed, so a browser keeps a good copy while processing fails. A request by any other method whose If-None-Match matches, such as a POST to the JSON endpoint, gets 412 Precondition Failed. An If-None-Match that is neither "*" nor a list of entity tags matches nothing. Otherwise the response carries 'Cache-Control: max-age=1800, private', or the max age given, and the ETag, or 'Cache-Control: private, no-cache' and no ETag when processing recorded errors. Both carry a Vary header naming the headers the pipeline's elements accept, whether or not the request carried them.
