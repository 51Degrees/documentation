fiftyone_pipeline_examples.cloud.engines Namespace Reference

Detailed Description

The cloud engines the mixed examples add to a pipeline.

The 51Degrees cloud service answers one request with a section for each product the key in use carries. A cloud request engine makes that request, and each engine after it reads its own section of the answer into the flow data, so one request serves device detection, IP intelligence and the translated country names together.

Each engine that reads a section needs a cloud request engine earlier in the same pipeline, and the key has to carry at least one property from that section, or the pipeline cannot be built. The cloud request engine comes from the fiftyone_pipeline_cloudrequestengine package, which takes a resource key or a licence key with the list of properties wanted.
