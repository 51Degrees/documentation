_endpoint_from_environment ( )
protected

The cloud end point the environment gives, or None when it gives none.

Constants.CLOUD_ENDPOINT is read first. When it is unset or empty the variable Constants.FOD_CLOUD_API_URL names is read, which is the old name, and the first use of it is reported as deprecated. The report is a FutureWarning, which Python shows by default, because the people who set the variable are the ones running the application.

@rtype: string

Returns
: the end point, or None
