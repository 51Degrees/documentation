tests.test_credentials.TestCredentials Class Reference

Detailed Description

Checks every combination of resource key, licence key and requested properties in the Credentials table of the cloud request engine specification, and where each credential travels in the requests the engine makes.

◆ test_properties_the_answer_leaves_out_are_reported_once()

tests.test_credentials.TestCredentials.test_properties_the_answer_leaves_out_are_reported_once ( self) 
The service drops a property the licence key does not cover
without naming it. The engine compares the list it sent with the
answer, warns once naming the missing property, and does not warn
again on the next request. A property present but null counts as
answered, because its nullreason explains it.
