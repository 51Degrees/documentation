requested_package_sizeThe usage element will group data into single requests before sending it. This setting controls the minimum number of entries before data is sent, and a message holds from this to twice this number. 50 by default. If you are sharing large amounts of data, increasing this value is recommended in order to reduce the overhead of sending HTTP messages. For example, the 51Degrees cloud service uses a value of 2500. @type cookie: string

track_sessionIf True, the cookie named by cookie is used to tell user sessions apart, so evidence already shared is shared again when it comes from a new session. False by default. It needs cookie to be set, and has no effect when share_all is True, because every cookie is then shared and used to find repeats. @type query_whitelist: list
query_whitelistBy default query string and HTTP form parameters are not shared unless prefixed with '51D_'. If you need to share query string parameters, a list can be specified here. None shares every parameter. @type header_blacklist: list

protected

Send the entries still queued when closing, even if there are fewer than the requested package size.

A send already running finishes first, so only one message goes out at a time. Nothing is sent while paused, after a message fails, or once deadline has passed, and the entries left are discarded. Closing logs the ones left when the time ran out, and this logs the ones left for the other two reasons.

@type deadline: float

◆ close()

fiftyone_pipeline_engines_fiftyone.share_usage.ShareUsage.close ( self)

Wait for any usage data already being sent, then send what is still queued and stop the threads that send it.

The pipeline calls this when it is closed. Closing does not wait for a pause after failed sends, and sends nothing while paused.

Closing gives up after cleanup_timeout_seconds, discards the entries still queued and logs a warning, so that it does not hold up the process that closes it. A message already going out when that time passes is left to the request timeout on its own thread.

◆ share_send_usage()

fiftyone_pipeline_engines_fiftyone.share_usage.ShareUsage.share_send_usage ( self)

Internal method to start sending the queued usage data to the 51Degrees servers.

Nothing starts if a thread is already sending, if fewer than requested_package_size entries are queued, or while sending is paused after failed sends, in which case a timer starts sending when the pause ends.
