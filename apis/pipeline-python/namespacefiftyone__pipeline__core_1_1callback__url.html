fiftyone_pipeline_core.callback_url Namespace Reference

Detailed Description

The callback URL the client script posts to for updated JSON.

The protocol and host usually come from the request, and the script holds the URL in a single-quoted string, so the URL is checked before it is written into the script. A URL that is not valid is refused. In the user information, in anything after the host and port, and in the endpoint, the characters a URL cannot hold or that could end the string or the script are percent-encoded.

See https://github.com/51Degrees/specifications/blob/main/pipeline-specification/pipeline-elements/javascript-builder.md#callback-url

The user information, host and port as they are written into the URL, or None when they are not valid.

The user information ends at the first '@', so a second '@' is part of the host and refused.

◆ _checked_host_port()

_checked_host_port ( host_port)
protected

The host and optional port in lower case, or None when they are not valid.

The host is an IPv6 address in brackets with an optional zone identifier, or a name of labels separated by dots with a dot allowed at the end. The port is ':' followed by digits up to 65535, or by nothing.

The number of 16 bit groups in a run of groups separated by ':', or -1 when the run is not valid.

An empty run has none, and an IPv4 address at the end of the run, where one is allowed, counts as two.

◆ _is_ipv6()

_is_ipv6 ( text)
protected

Whether the text is an IPv6 address as RFC 3986 section 3.2.2 defines one.

That is eight groups of one to four hexadecimal digits separated by ':', where one '::' can stand for one or more groups of zeros and the last two groups can be written as an IPv4 address.

◆ callback_url()

callback_url ( protocol,
host,
endpoint )

Build the callback URL from its parts and check it.

One slash separates the host and the endpoint, being added when neither has one and removed when both do. The protocol and the host are written in lower case and the rest as given, apart from the percent-encoding.

@type protocol: str

Parameters
protocolThe protocol, such as https @type host: str
hostThe host, which can start with user information and end with a port, a path, a query or a fragment @type endpoint: str
endpointThe endpoint @rtype: CallbackUrl
Returns
: The callback URL, or None when the protocol, host or endpoint is not set
