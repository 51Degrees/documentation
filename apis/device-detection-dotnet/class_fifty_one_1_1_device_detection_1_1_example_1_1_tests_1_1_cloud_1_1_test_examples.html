FiftyOne.DeviceDetection.Example.Tests.Cloud.TestExamples Class Reference

Detailed Description

This test class ensures that the cloud examples execute successfully.

Note that these test do not generally ensure the correctness of the example, only that the example will run without crashing or throwing any unhandled exceptions.
