Detailed Description

The input data, read from the environment variable names every language's copy of this demo reads.

Each value is read from its runtime name first, being the name a developer sets in their own shell. Only the resource key has a second name, the one continuous integration sets. That name starts with an underscore, because a shell cannot export a name that starts with a digit, and ends with the product this demo needs, being the 51Did.

Neither value is ever written to the console or a log, because a resource key is not for publishing and an endpoint can name a host that is not public. Only the name of the variable each came from is.
