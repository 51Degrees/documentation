FiftyOne.DeviceDetection.Hash.Engine.OnPremise.FlowElements.DeviceDetectionHashEngine Class Reference

Detailed Description

Hash device detection engine.

This engine takes User-Agents and other relevant HTTP headers and returns properties about the device which produced them e.g. DeviceType or ReleaseDate. See the Specification
