FiftyOne.Pipeline.DerivedProperty.FlowElements.DerivedPropertyElement Class Reference

Detailed Description

Computes new properties from properties other elements have already put into the flow data, following one or more scripts.

The element holds no data file, makes no request and uses no resource key, so it is a plain flow element rather than an aspect engine.
