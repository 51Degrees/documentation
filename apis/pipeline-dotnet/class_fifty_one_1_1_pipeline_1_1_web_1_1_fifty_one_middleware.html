FiftyOne.Pipeline.Web.FiftyOneMiddleware Class Reference

Detailed Description

The 51Degrees middleware component.

This carries out the processing on the device making the request using the Pipeline which has been constructed, and intercepts requests for the 51Degrees JavaScript.

async Task FiftyOne.Pipeline.Web.FiftyOneMiddleware.Invoke ( HttpContext context)

Called as part of the MVC pipeline.

The component serves JavaScript if needed. If not, it populates an IFlowData object from the HttpContext and processes it using the IPipeline. The IFlowData instance is added to the HttpContext so it can easily be accessed by other code.
