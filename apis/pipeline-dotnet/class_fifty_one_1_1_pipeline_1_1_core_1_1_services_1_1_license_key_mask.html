FiftyOne.Pipeline.Core.Services.LicenseKeyMask Class Reference

Detailed Description

Masks license keys in text, so a log entry or an error message never holds one in full.

A masked key shows only its last 4 characters. See the Specification

Make an exception whose message, and the messages of the exceptions inside it, hold each license key only in masked form.

A library often puts the URL it requested in its message, so this stands in for such an exception when it is logged or wrapped. The stand-in names the type of the original and keeps its stack trace as text.

static

Mask the license keys in some text.

The text can be a URL, a message or the message of an exception. A key is masked where it is a value of a query parameter called LicenseKeys, License or Licence, and wherever one of the supplied keys appears.

Parameters
textThe text to mask.
knownKeysKeys to mask wherever they appear, whether plain or encoded for a URL. Null or empty entries are ignored. A key of 4 or fewer characters is replaced entirely, so it is masked wherever the same text appears, including inside other words.
Returns
The text with each key masked.
