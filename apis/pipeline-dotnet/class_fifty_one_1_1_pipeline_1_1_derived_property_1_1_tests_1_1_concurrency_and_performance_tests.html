Times a long run of requests through one element and reports nanoseconds per request with the machine the run happened on.

Nothing here fails on a timing. A build agent that is busy is not a defect, and a test that fails on a slow machine would be turned off rather than read, so the only thing asserted is that the work was done. The numbers go to the test output for a person to read.
