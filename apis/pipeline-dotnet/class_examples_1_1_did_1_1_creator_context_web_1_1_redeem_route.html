Examples.Did.CreatorContextWeb.RedeemRoute Class Reference

Detailed Description

The server-side step of the creator context flow, and the part a developer copies into their own server.

It parses the 51Did the page sent, checks the signature offline against the published keys, redeems the encrypted result with the licence key, and answers the page in the cloud's own shape plus one extra field, serverSignature, with the offline outcome.
