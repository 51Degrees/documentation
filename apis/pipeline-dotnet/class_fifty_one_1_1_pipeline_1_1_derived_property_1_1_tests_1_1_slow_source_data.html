FiftyOne.Pipeline.DerivedProperty.Tests.SlowSourceData Class Reference

Detailed Description

Aspect data for SlowSourceEngine.

It has to be aspect data rather than plain element data, because lazy loading is a feature of an aspect engine and the waiting happens inside AspectDataBase.
