FiftyOne.Pipeline.AgentSignature.Tests.Rfc9421AppendixBTests Class Reference

Detailed Description

Pins this element to the worked examples that RFC 9421 Appendix B prints.

The appendix is the strongest check available on the signature base builder, because the base it prints is the standard's own output rather than ours, so a base built any other way is wrong no matter how self consistent the rest of the code is.

These are unit tests of the signature base builder and of the verifier, not of the flow element. Several of the examples cover components the element cannot rebuild from pipeline evidence, being '@method', '@path', '@target-uri', '@query' and the '@status' of a response, so a real request shaped like B.2.3 or B.2.6 would read Unverified with the ComponentUnavailable reason rather than verifying. The limitation is written up on AgentSignatureElement.FlowDataComponentResolver in FiftyOne.Pipeline.AgentSignature/FlowElement/AgentSignatureElement.cs and the follow-up work is to put the request line into evidence so that those components can be rebuilt. The tests below feed the component values in directly instead, which is what lets the base builder be checked against the standard on its own.

The values in the fixture were unfolded from the published RFC text using the convention of RFC 8792, where a line ending in a backslash continues on the next line and the leading whitespace of that next line is not part of the value. See Fixtures/SOURCE.txt.

◆ RsaKeyWithoutAlgorithmIsNotSupported()

void FiftyOne.Pipeline.AgentSignature.Tests.Rfc9421AppendixBTests.RsaKeyWithoutAlgorithmIsNotSupported ( )

The RSA key of the Appendix B.1.2 example settles on nothing when the signature names no algorithm, so the element refuses it rather than guessing.

RFC 9421 section 3.3 registers several algorithms that an RSA key can be used with, and the key itself does not say which. The Appendix B.2.1 to B.2.3 examples carry no 'alg' parameter, so a real request shaped like them would read as an algorithm this element cannot settle on.

◆ SharedSecretIsNotSupported()

void FiftyOne.Pipeline.AgentSignature.Tests.Rfc9421AppendixBTests.SharedSecretIsNotSupported ( )

The shared secret of the Appendix B.1.5 example settles on the RFC 9421 registry name 'hmac-sha256' and reads as not supported, so the element refuses the Appendix B.2.5 signature rather than checking it.

Web Bot Auth forbids shared secrets because anyone who can check such a signature can also make one.

◆ SharedSecretSignatureIsNotVerified()

void FiftyOne.Pipeline.AgentSignature.Tests.Rfc9421AppendixBTests.SharedSecretSignatureIsNotVerified ( )

A signature made with the shared secret of Appendix B.1.5 is never checked, so handing the Appendix B.2.5 signature to the verifier answers false rather than accepting it.

This is the promise that follows from the resolution above.
