FiftyOne.Pipeline.Core.Data.IFlowWarning Interface Reference

Detailed Description

Represents something the caller should know about the request that did not stop it being served.

For example, an evidence value that an element could not use.

Warnings are deliberately separate from IFlowError. A non-empty errors collection makes the pipeline throw at the end of processing unless the host suppresses process exceptions, so an element cannot use an error to explain a recoverable problem without risking the whole response. A warning never affects processing.
