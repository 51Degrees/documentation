pub const NEEDS_ENTERPRISE_DATA_FILE

Printed in place of a value when the data file in use does not carry the property.

Name the properties an example asks for that the data file in use does not carry, and say where to ask about the Enterprise data file.

The on-premise examples run on the free data files and also ask for properties only the Enterprise data file has. Each example passes the property names its engine reports for the loaded data file, so a property the file does not carry is told apart from one the file carries but has no value for with the evidence given.
