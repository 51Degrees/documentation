◆ close()

fiftyone\pipeline\devicedetection\SwigData::close ( )

Release the native results, which keep the engine's data in memory while they are held, even after the data has been refreshed.

Values already read are unaffected, and reading a property afterwards throws an exception. Closing the FlowData closes its results.
