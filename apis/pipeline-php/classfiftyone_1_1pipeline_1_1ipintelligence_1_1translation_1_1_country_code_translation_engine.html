fiftyone\pipeline\ipintelligence\translation\CountryCodeTranslationEngine Class Reference

Detailed Description

Engine 1: translates the weighted ISO country codes emitted by the IP intelligence engine (CountryCodesGeographical / CountryCodesPopulation) into weighted English country names (CountryNamesGeographical / CountryNamesPopulation), using countrycodes.en_GB.yml.

Mirrors ip-intelligence-dotnet's CountryCodeTranslationEngine: it is just the property map below passed to the base translation engine with a fixed en_GB language and the Original missing behaviour.
