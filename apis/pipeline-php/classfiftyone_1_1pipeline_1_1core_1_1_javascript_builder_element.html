fiftyone\pipeline\core\JavascriptBuilderElement Class Reference

Detailed Description

The JavaScriptBuilder aggregates JavaScript properties from FlowElements in the Pipeline.

This JavaScript also (when needed) generates a fetch request to retrieve additional properties populated with data from the client side It depends on the JSON Bundler element (both are automatically added to a Pipeline unless specifically removed) for its list of properties. The results of the JSON Bundler should also be used in a user-specified endpoint which retrieves the JSON from the client side. The JavaScriptBuilder is constructed with a url for this endpoint.

fiftyone\pipeline\core\JavascriptBuilderElement::getSequence ( $value)
static

The sequence to render into the script.

The template writes the sequence as bare code (var sequence = ...;), so anything other than a whole number would stop the script parsing, or change what it does. The value is the SequenceElement's sequence when parseSequence can use it, up to the largest sequence the SequenceElement gives, and 1 otherwise, because the script counts its own requests up from this number and cannot use zero or a negative one.
