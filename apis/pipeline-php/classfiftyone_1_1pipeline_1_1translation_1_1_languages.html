Resolve an Accept-Language value to an available locale.

Resolution rules, applied to each candidate in quality order:

  1. An exact case-insensitive match against an available locale wins.
  2. Otherwise, if the candidate's language is the base language (en), stop and return false - the source values are already English, so do not fall through to a lower-priority language.
  3. Otherwise, if the candidate is a two-letter language code, fall back to the first available locale that starts with it.
