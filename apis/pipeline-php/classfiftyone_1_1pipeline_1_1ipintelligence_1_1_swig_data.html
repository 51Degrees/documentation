fiftyone\pipeline\ipintelligence\SwigData Class Reference

Detailed Description

Extension of AspectData for retrieving results created by the SWIG wrapper of the on-premise IP intelligence engine.

Property values (or the lack of one) are returned in an AspectPropertyValue. Weighted properties (for example Mcc) are returned as a list of ['value' => ..., 'rawweighting' => ...] arrays, matching the shape returned by the cloud engine.
