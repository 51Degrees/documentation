fiftyone\pipeline\translation\YamlMap Class Reference

Detailed Description

Minimal parser for the flat "key: value" YAML maps used by the country translation files.

The files contain one mapping per line and no nesting, so a full YAML library is not required. Insertion order is preserved (PHP associative arrays are ordered), which matters because the country code file order defines the order of all known countries.
