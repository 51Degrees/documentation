fiftyone\pipeline\ipintelligence\IpIntelligenceOnPremise Class Reference

Detailed Description

The on-premise IP intelligence engine uses a local data file (.ipi) to generate a set of properties about an IP address supplied as evidence.

It wraps the native IpIntelligenceEngineModule produced by SWIG from 51degrees-cxx.

Mirrors DeviceDetectionOnPremise in device-detection/onpremise and IpIntelligenceOnPremise in 51degrees-python.

◆ close()

fiftyone\pipeline\ipintelligence\IpIntelligenceOnPremise::close ( )

Release the native engine this element built from its dataFile setting.

Its data is freed once no results read from it are still held, so close every FlowData it processed as well. The shared global engine belongs to the extension and stays loaded. Closing the Pipeline closes the element.

◆ getEvidenceKeyFilter()

fiftyone\pipeline\ipintelligence\IpIntelligenceOnPremise::getEvidenceKeyFilter ( )

The accepted evidence keys (query.client-ip, server.client-ip, query.client-ip-51d, ...).

Note that this engine performs a single-IP lookup: only the first parseable IPv4/IPv6 value from the evidence (in the priority order used by getClientIps) actually drives the lookup. This is not multi-evidence detection.
