<p>
This example requires a local data file. The free 'Lite' data file can be downloaded with the
scripts in the <a href="https://github.com/51Degrees/data">data</a> GitHub repository, which
this repository includes at <code>cxx/data</code>. Fetch the submodules by running
<code>git submodule update --init --recursive</code>, then run
<code>sh cxx/data/get-data-files.sh 51Degrees-LiteV4.1.hash</code> from the repository root,
which saves the file as <code>cxx/data/device-detection/51Degrees-LiteV4.1.hash</code>.
</p>
<p>
The Lite data file is only used for illustration, and has limited accuracy and capabilities.
Find out about the more capable data files that are available on our 
<a href="https://51degrees.com/pricing">pricing page</a>.
</p>
