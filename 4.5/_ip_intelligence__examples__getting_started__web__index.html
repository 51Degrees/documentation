IP Intelligence web quick start

Introduction🔗

The Getting Started Web examples show how to add 51Degrees IP Intelligence to a web application. The pipeline runs on each incoming HTTP request, reads the client IP from the headers, and exposes geolocation, network classification and connection-type properties (country, region, city, ASN, registered name, estimated bandwidth, mobile carrier, and more) to your handler so you can personalize the response, enforce regional rules, or route traffic.

Two deployment models are covered:

  • Cloud calls our hosted service over HTTPS. You do not manage a local data file or detection binary. See IP Intelligence cloud web quick start.
  • On-premise runs the IP Intelligence engine in your process with a local data file. Use it for offline operation or when latency and throughput are priorities. See IP Intelligence on-premise web quick start.

For both examples, configure a pipeline, register it with your framework, pass it the request, and read the result properties. Select a tab for your language and framework. For console or batch-style integrations, see IP Intelligence console quick start instead.
