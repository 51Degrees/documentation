fiftyone_pipeline_engines.datafile_update_service.DataFileUpdateService.track_local_data_file_changes ( self,
data_file )

Check for local changes to a datafile.

Used by the file system watcher. A file that has been written to is an event, and the refresh takes the same route as the polling one, so the attempt is logged, a failure carries the errors table's message and level, and the result is reported to the update complete callbacks either way. The next check is scheduled whatever happens, so that a later file is still picked up, until the data file is unregistered. @type data_file: DataFile

fiftyone_pipeline_engines.datafile_update_service.DataFileUpdateService.update_from_memory ( self,
data_file,
data )

Refresh a data file from the bytes given, without downloading anything.

A data file kept on disk has the bytes written to its path first, as the update route writes a download, and the engine is then refreshed from the file. @type data_file: DataFile

Parameters
data_fileDatafile to update @type data: bytes
dataThe new content of the data file @rtype: UpdateStatus
Returns
: AUTO_UPDATE_SUCCESS, AUTO_UPDATE_REFRESH_FAILED if the engine could not use the data (the data it had is kept), the status of a failed write for a data file kept on disk, which is not refreshed because its engine reads the file, or AUTO_UPDATE_NOT_NEEDED if the data file's engine has been closed
