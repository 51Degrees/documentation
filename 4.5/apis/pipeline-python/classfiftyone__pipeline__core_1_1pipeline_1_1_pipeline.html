fiftyone_pipeline_core.pipeline.Pipeline Class Reference

Detailed Description

Pipeline holding a list of FlowElements for processing, can create FlowData that will be passed through these, collecting ElementData Should be constructed through the PipelineBuilder class.

◆ close()

fiftyone_pipeline_core.pipeline.Pipeline.close ( self)

Close the flow elements, which releases the native data they hold and stops the updates of their data files, unless the pipeline was built with auto_close_elements set to false.

Use a with statement so that this happens when the pipeline is finished with.

FlowData created by the pipeline are not closed by it. Close each one as well, because the results it holds keep the engine's data in memory until they are released.
