fiftyone\pipeline\ipintelligence\IpIntelligencePipelineBuilder Class Reference

Detailed Description

The IpIntelligencePipelineBuilder builds a Pipeline that uses the 51Degrees cloud service to look up IP intelligence data.

It wires up a CloudRequestEngine followed by an IpIntelligenceCloud engine.

Mirrors device-detection-php's DeviceDetectionPipelineBuilder and location-php's GeoLocationPipelineBuilder.
