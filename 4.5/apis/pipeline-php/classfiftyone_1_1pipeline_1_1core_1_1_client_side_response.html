fiftyone\pipeline\core\ClientSideResponse Class Reference

Detailed Description

The response to a request for the client-side JavaScript or JSON, as Utils::javascriptResponse() and Utils::jsonResponse() build it.

Building it sends nothing, so send() writes it once it is complete.
