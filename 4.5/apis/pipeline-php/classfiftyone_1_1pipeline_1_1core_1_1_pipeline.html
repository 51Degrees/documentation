Member Function Documentation

◆ close()

fiftyone\pipeline\core\Pipeline::close ( )

Close the FlowElements that have a close method, which releases the native resources they hold, unless the autoCloseElements setting is false.

Call it in a finally block once the Pipeline is finished with.

FlowData created by the Pipeline are not closed by it. Close each one as well, because the results it holds keep the engine's data in memory until they are released.

Field Documentation

◆ $autoCloseElements

bool fiftyone\pipeline\core\Pipeline::$autoCloseElements

If true, the default, closing the Pipeline closes its FlowElements.

Set the autoCloseElements setting to false when the elements are shared with another Pipeline, and close each element once every Pipeline using it is finished with.
