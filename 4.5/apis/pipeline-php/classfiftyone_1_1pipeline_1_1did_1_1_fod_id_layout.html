fiftyone\pipeline\did\FodIdLayout Class Reference

Detailed Description

The byte offsets and lengths of the 51Did payload, for this package and its tests only.

The layout itself is published at https://github.com/51Degrees/specifications/blob/main/did-specification/identifier-layout.md which is the authority for what each byte holds, and https://github.com/51Degrees/specifications/blob/main/did-specification/package-surface.md lists what every 51Did package offers a caller.

A caller reads a 51Did through the named accessors on {
