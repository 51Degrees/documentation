fiftyone\pipeline\translation\Translator Class Reference

Detailed Description

Translates values using a single locale's translation map.

Handles a plain string, a list of strings, and a weighted list of strings (an array of ['value' => string, 'weighting' => number] entries). For a weighted list each entry's weighting is preserved unchanged and only its value is translated.
