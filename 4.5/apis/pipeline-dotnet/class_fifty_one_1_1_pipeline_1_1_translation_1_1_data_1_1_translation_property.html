Creates a translation whose no-value placeholder is typed for the readers of the destination property.

Template Parameters
TDestinationThe value type readers of the destination property expect, i.e. the T of the IAspectPropertyValue<T> they read it as. When the source property has no value, the placeholder stored against the destination is created with this type so typed reads of the destination do not fail with an invalid cast.
