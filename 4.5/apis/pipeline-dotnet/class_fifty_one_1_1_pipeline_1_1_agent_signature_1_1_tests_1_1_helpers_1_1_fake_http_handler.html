FiftyOne.Pipeline.AgentSignature.Tests.Helpers.FakeHttpHandler Class Reference

Detailed Description

An HttpMessageHandler that answers from a table of URLs rather than from the network, counts what it was asked for, and can be held open so that a test can see what a request does while a fetch is still running.
