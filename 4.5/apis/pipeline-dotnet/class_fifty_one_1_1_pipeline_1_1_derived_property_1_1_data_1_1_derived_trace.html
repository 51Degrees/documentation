Detailed Description

A record of one run of one script, being what every source property did, what every check answered, and which rule supplied the answer.

A trace is for tests, for the tester page and for anyone working out why a script gave the answer it gave. Nothing on the request path asks for one, so running a pipeline costs nothing for the trace to exist.
