FiftyOne.Pipeline.JavaScript.Tests.UserPromptHookTests Class Reference

Detailed Description

Unit tests for the builder's decision to render the user prompt block, which is test 20 of pipeline-dotnet#414.

The rendered script is checked in UserPromptRenderTests and the browser side in UserPromptBrowserTests.
