◆ ClientSideEvidenceEnabled

bool FiftyOne.Pipeline.Web.Shared.PipelineWebIntegrationOptions.ClientSideEvidenceEnabled
getset

True if client-side properties should be enabled.

If enabled (and the JavaScriptBundlerElement added to the Pipeline), a client-side JavaScript file will be served at the path JavaScriptPath.

◆ JavaScriptPath

string FiftyOne.Pipeline.Web.Shared.PipelineWebIntegrationOptions.JavaScriptPath
getset

The path of the request that is answered with the client-side JavaScript.

A request whose path ends with this value is intercepted. A blank value gives the default, which is /51Degrees.core.js.

◆ JsonPath

string FiftyOne.Pipeline.Web.Shared.PipelineWebIntegrationOptions.JsonPath
getset

The path of the request that is answered with the client-side JSON.

A request whose path ends with this value is intercepted. When the web integration adds the JavaScript Builder Element itself, the script calls back to this path. A JavaScript Builder Element listed in the configured elements needs its Endpoint set to the same value. A blank value gives the default, which is /51dpipeline/json.

◆ SequenceElementEnabled

bool FiftyOne.Pipeline.Web.Shared.PipelineWebIntegrationOptions.SequenceElementEnabled
getset

True to add the Sequence Element to the Pipeline when it is not already in the configured elements.

If false, the web integration does not add it. The JSON Builder Element needs the sequence, so set ClientSideEvidenceEnabled to false as well, or list the Sequence Element in the elements. Defaults to true.

◆ SetHeadersElementEnabled

bool FiftyOne.Pipeline.Web.Shared.PipelineWebIntegrationOptions.SetHeadersElementEnabled
getset

True to add the Set Headers Element to the Pipeline when it is not already in the configured elements.

If false, the web integration does not add it. This differs from UseSetHeaderProperties, which stops the headers being written to the response. Defaults to true.
