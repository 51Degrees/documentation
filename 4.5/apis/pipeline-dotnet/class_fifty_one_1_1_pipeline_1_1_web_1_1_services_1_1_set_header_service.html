void FiftyOne.Pipeline.Web.Services.SetHeaderService.SetHeaders ( HttpContext context,
IFlowData flowData )
static

Set the HTTP headers in the response using values from the supplied flow data.

If the supplied headers already have values in the response then they will be amended rather than replaced. If the pipeline has no ISetHeadersElement, or the flow data has no data for it (its processing can fail before the data is added, for example when the cloud service could not be reached, with the pipeline configured to suppress process exceptions), then no headers are set. The upstream failure is already reported by the pipeline's own error handling.

Parameters
contextThe HttpContext to set the response headers in
flowDataThe flow data containing the headers to set.
