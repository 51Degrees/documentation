Detailed Description

Builds a pipeline holding one agent signature element and runs requests through it, reaching the element through its public surface alone.

The main test project has a richer harness, which cannot be shared here because it sets the element's clock through an internal member that only the main test assembly may see. This harness needs no clock, because the times the signing helper writes are fixed points that stay valid, and the element checks a key's own validity at the signature's created time rather than at the present moment.
