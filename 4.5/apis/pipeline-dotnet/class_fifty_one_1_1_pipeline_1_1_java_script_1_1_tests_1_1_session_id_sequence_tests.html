FiftyOne.Pipeline.JavaScript.Tests.SessionIdSequenceTests Class Reference

Detailed Description

Checks that the session id and the sequence reach the client script only in a form that cannot break it.

The session id is written inside quotes and the sequence as a number, both as they are, so a session id that is not made of ASCII letters, digits and hyphens (1 to 64 of them) is written as an empty string, and a sequence that is not a positive 32 bit integer is written as 1.

No browser is used. The element is given the values as evidence with no Sequence Element in the pipeline, which is what reaches the script when a page sends them itself. The rendered script is checked with node –check, so Node must be on the path, and each test is inconclusive when it is not.
