FiftyOne.Pipeline.Translation.Tests.MissingSourcePropertyTests Class Reference

Detailed Description

Tests for the behavior of the translation engine when the source property cannot be read.

Aspect data (for example a cloud engine's data when the resource key does not include the property, or when the cloud request failed) throws PropertyMissingException from its indexer where plain element data returns null; both must result in a no-value placeholder rather than a per-request exception.
