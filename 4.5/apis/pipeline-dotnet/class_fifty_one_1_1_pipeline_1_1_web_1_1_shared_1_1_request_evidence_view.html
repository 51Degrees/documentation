FiftyOne.Pipeline.Web.Shared.RequestEvidenceView Class Referenceabstract

Detailed Description

A read only view of a web request, keyed as its values would be as evidence, for example 'header.user-agent', which a web integration adds to evidence as Core.Constants.EVIDENCE_HTTPREQUEST_KEY.

See the Specification

The values are read from the request the first time the view is used, so a request whose view nothing reads costs only this object. The view has to be read while the request is being handled.
