FiftyOne.Pipeline.JavaScript.Tests.UserPromptBrowserTests Class Reference

Detailed Description

Where the visitor's answer comes from, what reaches the wire and what does not.

What refresh() does and does not do, what the record holds, and the two changes of answer, on one page and across two.

A stored answer may be reused only for the same inputs, and no answer yet on a page where a platform is present means unknown rather than different.

The harness the user prompt browser tests are written against.

Tests 4 to 10 and 24 to 26 of pipeline-dotnet#414.

It is the SessionStorageCacheTests pattern with the additions work package pipeline-dotnet#414 asks for, being a stub 51Did element so the block renders, a record of every request body, page variants that place a preference platform on the page before the include, and a gate the test releases so a request can be held in flight without abandoning the page.

Tests 2 and 17 of pipeline-dotnet#414.

Tests 3, 11 to 13, 15 to 18 and 22 to 23 of pipeline-dotnet#414.
