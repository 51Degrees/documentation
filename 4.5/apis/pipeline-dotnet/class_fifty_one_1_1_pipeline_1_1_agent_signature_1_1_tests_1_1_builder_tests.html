FiftyOne.Pipeline.AgentSignature.Tests.BuilderTests Class Reference

Detailed Description

Checks that every setting the builder offers reaches the element and changes what the element does, that an element can be built from a pipeline configuration file, and that the element disposes the client it made itself whilst leaving a client it was given alone.
