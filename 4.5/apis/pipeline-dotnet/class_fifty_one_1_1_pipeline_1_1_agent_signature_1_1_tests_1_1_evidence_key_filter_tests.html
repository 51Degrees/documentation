FiftyOne.Pipeline.AgentSignature.Tests.EvidenceKeyFilterTests Class Reference

Detailed Description

Checks the evidence the element asks for.

A signature may cover any request header, so the element cannot write down the list in advance and asks for every header instead. The web integration only puts evidence into a request that some element has asked for, so a header the filter leaves out is a header no signature covering it can be checked against.
