FiftyOne.Pipeline.AgentSignature.Tests.MultipleSignatureTests Class Reference

Detailed Description

A request may carry more than one signature with the Web Bot Auth tag, which the protocol draft's reverse proxy case does, the agent's own signature plus the proxy's.

The draft has a verifier validate each independently, so the element checks each tagged signature until one verifies, reports the first tagged signature's outcome when none does, and bounds how many are checked because each can cost a directory wait and the header is written by the sender.
