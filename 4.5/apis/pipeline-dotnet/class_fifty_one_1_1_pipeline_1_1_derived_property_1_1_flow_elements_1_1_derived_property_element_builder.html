FiftyOne.Pipeline.DerivedProperty.FlowElements.DerivedPropertyElementBuilder Class Reference

Detailed Description

Builds a DerivedPropertyElement.

Scripts reach the builder three ways, being a script built into this package, a file in your own environment, or a string of script text from your own code. The three may be mixed in one element. There is no way to name a URL, because a script has to be readable at build and cannot change under a running pipeline.

Once Build returns, the element holds only the compiled scripts. No path, no text and no reference to where a script came from is kept.
