FiftyOne.Pipeline.DerivedProperty.Data.DerivedScriptValidationException Class Reference

Detailed Description

Raised where one or more scripts do not validate.

The message lists every fault, one per line, so a build failure says everything that has to be fixed rather than only the first thing found.
