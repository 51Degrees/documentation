Dictionary< string, object > FiftyOne.Pipeline.CloudRequestEngine.FlowElements.CloudAspectEngineBase< T >.CreateAPVDictionary ( Dictionary< string, object > cloudData,
IReadOnlyList< IElementPropertyMetaData > propertyMetaData )
protected

Use the supplied cloud data to create a dictionary of AspectPropertyValue<T> instances.

This method uses the meta-data exposed by the Properties collection to determine if a given entry in the supplied cloudData should be converted to an AspectPropertyValue<T> or not. If not it will be output unchanged. If it is then a new AspectPropertyValue<T> instance will be created and the value from the cloud data assigned to it. If the value is null then the code will look for a property in the cloud data with the same name suffixed with 'nullreason'. If it exists, then it's value will be used to set the noValueMessage on the new AspectPropertyValue<T>.

Parameters
cloudDataThe cloud data to be processed. Keys are flat property names (i.e. no '.' separators). Values are the property values.
propertyMetaDataThe meta-data for the properties in the data. This will usually be the list from Properties but will be different if dealing with sub-properties.
Returns
A dictionary containing the original values converted to AspectPropertyValue<T> instances where needed. Any entries in the source dictionary where the key ends with 'nullreason' will not appear in the output.
Exceptions
ArgumentNullExceptionThrown if a required parameter is null.
