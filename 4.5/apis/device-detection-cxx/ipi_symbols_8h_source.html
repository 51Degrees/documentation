26/*
27 * Gives the copy of common built for IP Intelligence its own linked names, so
28 * that one program can link both Device Detection and IP Intelligence. The two
29 * copies are compiled with definitions that change structure sizes, so each
30 * product has to bind to its own copy.
31 *
32 * Every function and global the common C files give external linkage is listed
33 * here. Types have no linked names, so they are not here, and no structure
34 * changes. Source code keeps using the fiftyoneDegrees names.
35 *
36 * Every common header includes this file first when
37 * FIFTYONE_DEGREES_IPI_SYMBOLS is defined, so declarations, definitions and
38 * callers are renamed together. A build that doesn't define it compiles as if
39 * this file didn't exist, which is what keeps language wrappers unchanged. It
40 * is a separate define because Device Detection builds and language wrappers
41 * can set FIFTYONE_DEGREES_LARGE_DATA_FILE_SUPPORT.
42 *
43 * ci/check-common-symbols.ps1 fails the build when a name is missing.
44 */
