Unaligned
  • Common

Detailed Description

Read and write numbers that can start at any byte.

The data file holds its records packed, so a number within it can start at any byte. Reading one through a pointer to its type is undefined when the address is not aligned to the type, and with vector instructions it can fault. Each function here copies the bytes of one number between the address given and a local of the number's type. The copy has a fixed size, so compilers make it a single load or store where the processor allows one.
