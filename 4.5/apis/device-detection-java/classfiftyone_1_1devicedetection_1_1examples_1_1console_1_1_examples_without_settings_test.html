fiftyone.devicedetection.examples.console.ExamplesWithoutSettingsTest Class Reference

Detailed Description

Runs each on-premise console example's main with no arguments and no licence key, as someone who has just cloned the repository runs it, and checks that it says what the Enterprise data file adds, with the link to the contact page.

The examples default to the free Lite data file. CI gives the other tests the Enterprise data files, so nothing else tests what a fresh clone shows.
