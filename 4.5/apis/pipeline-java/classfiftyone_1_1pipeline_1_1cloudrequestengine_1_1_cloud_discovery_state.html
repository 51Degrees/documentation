fiftyone.pipeline.cloudrequestengine.CloudDiscoveryState Class Reference

Detailed Description

A copy of what the Cloud Request Engine discovered for a resource key, being the accepted Evidence keys and the accessible properties, which depend only on the resource key.

Read it from the builder after a successful build, keep it, for example as toJson(), and give it to a later builder, which then makes no discovery request. A Pipeline can so be built offline, and a host that starts often need not call the cloud service each time.
