FiftyOne.IpIntelligence.Example.Tests.OnPremise.TestExamplesWithoutSettings Class Reference

Detailed Description

Runs each console example as someone who has just cloned the repository does, through its Main method with no arguments and none of the settings the other tests are given.

So the examples use the free data files that the data repository links, and these tests check that each one runs on them and says what the Enterprise data file adds.
