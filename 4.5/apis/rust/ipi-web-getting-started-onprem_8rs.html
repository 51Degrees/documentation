◆ build_app()

pub struct DataFileNotes build_app ( data_file:&std::path::Path ,
share_usage:bool  ) -> anyhow::Result<(Router, DataFileNotes)>

Build the on-premise web application router plus the data-file notes.

The engine is built once so its data-file warnings (free tier, and over 30 days old) can be read with [examples_shared::check_data_file] and shown on the page, along with the properties the data file carries, which say which rows need the Enterprise data file. The very same engine instance is then used as an application element of the web pipeline. Usage sharing is added first (REQUIRED for a web example).

share_usage is true when the binary serves the page. The tests pass false, so a test run sends nothing to 51Degrees.

◆ get()

async fn get ( app:Router ,
uri:& str ) -> Response

Drive one GET request through a clone of the app and return the response.

A clone is used (cloning a Router is cheap, sharing the same Arc elements) so the owning app the caller holds outlives the request. With usage sharing on, the app wraps a blocking reqwest client whose backing runtime must not be dropped from inside an async context, so keeping the owning app in the synchronous test body lets its final drop happen outside the runtime.

Build the app for the test, skipping when no data file is available.

The test pins the ASN tier so it always exercises the small, current, always-loadable 4.5 ASN file, independent of whether the production Enterprise share happens to be mounted on the build machine. The binary itself uses IpiTier::default(), the Enterprise file or the Lite file.
