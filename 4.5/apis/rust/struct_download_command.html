DownloadCommand Struct Reference

Detailed Description

The command that runs the data repository's download script for one file.

On Windows that is the PowerShell script, in PowerShell 7 when it is on the PATH and otherwise in Windows PowerShell without the module path it would inherit from PowerShell 7. Everywhere else it is the shell script in sh.
