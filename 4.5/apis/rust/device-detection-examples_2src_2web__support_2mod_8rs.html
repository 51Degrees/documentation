◆ detection_results_table()

pub fn detection_results_table ( device:&dyn ElementData,
available:Option<&[String]>  ) -> String

Render the server-side detection results as a .c-eg-table.

device is the device element data read from the flow data. Each displayed property is rendered through [examples_shared::get_property_as_string], so a missing or no-value property shows the standard marker rather than failing.

available is the on-premise engine's properties, which are those its data file carries, or None for the cloud. An Enterprise property the data file does not carry says it needs the Enterprise data file, with a link to ask about a copy.
