◆ deprecated_names

mod deprecated_names

The file every test and example reads a renamed environment variable through, deprecated-names/environment.rs. The new name is read first, and the deprecated name it replaced is read when the new one is unset or empty. The rule is tested against a stand-in for the environment. What is said on standard error is tested in a child process, because the line is said once for the life of a process and a test's own standard error cannot be read from inside it.
