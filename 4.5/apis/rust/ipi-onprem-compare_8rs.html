◆ PerformanceProfile

pub struct ExampleOptions PerformanceProfile = PerformanceProfile::LowMemory

The profile the two IP addresses are compared under unless --profile names another.

LowMemory reads the data file from disk, so the comparison needs little memory even with the Enterprise file, which is over 6 GB. Reading from disk is much slower, and the .NET metrics example read a profile's values about 166 times a second with LowMemory against 2,013 with the file held in memory, so --profile HighPerformance is offered where there is memory for the whole file.
