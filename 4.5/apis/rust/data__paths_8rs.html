◆ IpiTier

enum IpiTier

Which tier of IP Intelligence data file to resolve.

With no file set, an example that shows location or registration properties reads the Lite file, and one whose properties do not matter to what it shows, such as a performance or update example, reads the much smaller ASN file. Either reads the Enterprise file instead when the configured share is reachable. A caller can also force a specific tier, for example to exercise the Enterprise-only properties.

◆ dd_data_path()

pub enum IpiTier dd_data_path ( ) -> Option< PathBuf >

Resolve the path to an on-premise Device Detection data file.

Checks [DD_PATH_ENV_VAR] first and returns its value when set to a non-blank path. Otherwise finds [DD_LITE_RELATIVE_PATH] with [find_data_file], which downloads it when it is missing. Returns None if neither is available.

◆ find_data_file()

pub fn find_data_file ( relative_path:& str) -> Option< PathBuf >

Find a data file the data repository links to, downloading it when it is missing.

relative_path is looked for as [crate::find_file] looks for it. The data repository lists each data file as <file>.link in the folder where the file goes, so when the file is missing and its link is there, the data repository is the folder above, and its script is run for that one file, saying so. The file is then looked for again. When it still cannot be found, a message naming the command that gets it is printed and None is returned.

◆ ipi_data_path()

pub fn ipi_data_path ( tier:IpiTier ) -> Option< PathBuf >

Resolve the path to an on-premise IP Intelligence data file at the requested tier.

[IPI_PATH_ENV_VAR] always wins when set to a non-blank path, regardless of tier, so a caller can point every example at one explicit file. Otherwise the tier decides:

  • [IpiTier::EnterpriseOrLite] and [IpiTier::EnterpriseOrAsn] return the latest Enterprise file from the configured share if it is reachable, and otherwise that free file.
  • [IpiTier::Enterprise] returns the latest Enterprise file, or None when the share is unreachable.
  • [IpiTier::Asn] and [IpiTier::Lite] return that free file, found with [find_data_file], which downloads it when it is missing.

Returns None when no file for the requested tier can be located.
