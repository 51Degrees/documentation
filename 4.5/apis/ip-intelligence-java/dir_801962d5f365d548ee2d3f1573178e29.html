Introduction

These examples are not distributed as maven jars and need to be built by you.

Required Files

The data files for on-premise IP intelligence are kept in cxx/data/ip-intelligence, a folder of the data repository, which is a submodule of cxx.

The examples use the free data files by default, so they run from a fresh clone with no settings. The examples that show location and network properties use the Lite file (51Degrees-LiteV41.ipi), which has the registration properties, and the performance and update examples use the much smaller ASN file (51Degrees-IPIV4AsnIpiV41.ipi). An example that cannot find its file runs the data repository's script to download it, and logs the command it runs. To download both first, run cxx/data/get-data-files.sh ip-intelligence from the root of this repository, or cxx\data\get-data-files.ps1 ip-intelligence in PowerShell on Windows.

Each example shows the properties that only the Enterprise data file has as needing it, and gives a link to ask for a copy. The Compare, Metrics and Suspicious examples need those properties, so with a free data file they say which they need and stop. Contact us for a copy of the Enterprise data file. To use it, place it in cxx/data/ip-intelligence and pass its path as the first argument, or set the _51DEGREES_IPI_PATH environment variable or system property to its path.

The Enterprise data file is over 6 GB, and the MaxPerformance profile loads all of it into memory, so the examples built for it, or that may be given it, use the LowMemory profile, which reads the file from disk as it is needed. Those are the Compare, Metrics, OfflineProcessing, Suspicious and UpdateDataFile examples. The Metrics and Compare examples take a profile as their fourth argument, and MaxPerformance there makes them faster on a machine with memory to hold the whole file.

The ExamplesWithoutSettingsTest tests run each console example as a fresh clone does. The other tests use the Enterprise data file, 51Degrees-EnterpriseIpiV41.ipi, when it is in cxx/data/ip-intelligence. When it is absent, the tests for examples that work with any data file fall back to the ASN file and then the Lite file. The OfflineProcessing and PerformanceBenchmark tests fall back to the Lite file only, and the tests of the Metrics, Compare and Suspicious examples with the Enterprise data file are skipped.

The examples locate the data file in the following order:

  1. The _51DEGREES_IPI_PATH environment variable or system property, which can be set to an explicit path to the data file. It is used in place of any file named without a full path.
  2. The path given as the first argument, or the free file the example uses by default, searched for below the folder the example is run from and then below cxx/data, so that the examples find it whether they are run from the root of this repository or from this folder.
  3. A free file that is still missing is downloaded by the data repository's script.

This project contains sub-modules - console, giving examples that are intended to be run from the command line/console and web, illustrating use of 51Degrees Web/Servlet integration. There is also a shared sub-module containing various helpers for the examples.

Among other things, the examples illustrate:

  • use of the fluent builder to configure a pipeline
  • use of a configuration options file to configure a pipeline
  • use of the cloud IP intelligence service
  • use of the on-premise IP intelligence service
  • use of IP intelligence pipeline for offline processing tasks
  • configuring IP intelligence trade-offs between speed and conserving memory

Examples

The tables below describe the examples available in this repository.

Cloud

Cloud examples require a resource key, supplied via the TestResourceKey environment variable, system property, or command line argument. Resource keys for IP Intelligence are not yet generally available, so these examples can also be pointed at a custom hosted cloud endpoint using the TestCloudEndPoint environment variable or system property.

Example Description
GettingStartedCloud (Console) How to use the 51Degrees cloud IP intelligence service to determine details about IP addresses.
GettingStartedWebCloud (Web) How to use the 51Degrees cloud IP intelligence service to determine details about IP addresses as part of a simple Java servlet website.
GetAllPropertiesCloud How to iterate over all properties returned by the cloud IP intelligence service for a given IP address.
MetadataCloud How to access the meta-data that relates to the properties available from the cloud IP intelligence service.

Cloud examples need a resource key. The key is read from the _51DEGREES_RESOURCE_KEY environment variable or system property first. The legacy TestResourceKey name is still supported and is checked second.

The cloud property tiers changed in May 2026. The examples and this documentation now reflect what is free and what needs a paid subscription.

  • Free tier IP properties are Country, LocationConfidence, Ip and IpV6.
  • Paid IP properties used by the examples are CountryCode, CountryCode3, Region, State, Town, TimeZoneOffset, RegisteredName, RegisteredOwner, RegisteredCountry, IpRangeStart, IpRangeEnd, Latitude, Longitude, Areas and AccuracyRadiusMin.

Running Examples and Tests

IMPORTANT: All examples and tests must be run from this folder, examples/ip-intelligence.

Running Tests

To run all tests:

# From examples/ip-intelligence
mvn test

To run tests for a specific module:

# Console tests
mvn test -pl console
# Web tests
mvn test -pl web/getting-started.onprem

Running Examples with Maven

Console examples can be run directly using Maven exec plugin:

# From examples/ip-intelligence
mvn compile exec:java -pl console -Dexec.mainClass="fiftyone.ipintelligence.examples.console.GettingStartedOnPrem"

Web examples:

# From examples/ip-intelligence
mvn compile exec:java -pl web/getting-started.onprem -Dexec.mainClass="fiftyone.ipintelligence.examples.web.GettingStartedWebOnPrem"

The web example will start a Jetty server on port 8081. Access it at: http://localhost:8081

Running Examples from Packaged JARs

Alternatively, you can build "fat" JARs and run examples from the command line.

First, build the packages:

mvn package

This will produce JARs with dependencies inside target subfolders.

Then run examples using the JAR:

java -cp .\console\target\ip-intelligence-java-examples.console-4.4.19-jar-with-dependencies.jar fiftyone.ipintelligence.examples.console.OfflineProcessing
