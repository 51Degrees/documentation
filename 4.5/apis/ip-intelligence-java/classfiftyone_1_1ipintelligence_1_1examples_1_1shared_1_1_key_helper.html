Obtain a resource key from the passed argument, from environment variable or from a property.

The aligned RESOURCE_KEY_VARIABLE name is checked first, then the deprecated RESOURCE_KEY_ENV_VAR, then the passed variable name. Store as System Property under the passed variable name.

The resource key for a test that calls the live cloud service, from SHARED_RESOURCE_KEY_NAMES and then the names getOrSetTestResourceKey() reads.
