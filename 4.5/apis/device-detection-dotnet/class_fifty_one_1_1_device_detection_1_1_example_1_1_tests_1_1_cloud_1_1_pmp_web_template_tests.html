FiftyOne.DeviceDetection.Example.Tests.Cloud.PmpWebTemplateTests Class Reference

Detailed Description

Checks the addresses the PMP web demo's templates carry once their placeholders are filled.

The PMP reads its resource key from the name of the script it was served as, so the key is part of a URL path rather than the value of an attribute. A key written straight into a template is only ever encoded for HTML, and HTML encoding leaves '/', '?', '#' and '' exactly as they were, so a key holding one of them would address a different part of the cloud. The tag loads as a script, so the page is told nothing and the demo shows an empty screen.

These tests fill every real template with a key that needs escaping and read the addresses back, so a template that builds an address out of its own parts again fails here rather than in a browser.
