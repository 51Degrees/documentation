tests.test_read_by_index Namespace Reference

Detailed Description

An engine built with a list of property names reads each one by its index in that list, with the native engine and the Lite data file.

Also prints how long a read by name and a read by index take. An engine built with no names takes the names the native code gives after the first load as its list, and reads by index too.
